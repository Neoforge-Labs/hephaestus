# Hephaestus

Hephaestus (`heph`) is NeoForge Labs' full-stack kit: the forge every NeoForge
product and research project is built from. Each project it creates is an
**ingot**. It spans Rust, Go, Python, TypeScript, Terraform, Compose and CI.

## Where this stands

Hephaestus is in Phase 1: the core and the local stack are under construction.
Every module is labelled `experimental`, which means its interfaces can change
without notice and nothing here should sit in a production money path yet. The
[roadmap](/roadmap) shows what comes next.
