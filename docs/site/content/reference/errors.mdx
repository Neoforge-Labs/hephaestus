# Error codes

Every problem+json error body the kit emits carries a `type` URL of the form
`https://heph.neoforgelabs.tech/errors/<code>`. Each code below has its own page
there, with the caller-facing message and developer guidance.

| Code | Status | Meaning |
| --- | --- | --- |
| [HEPH-GEN-500](/errors/HEPH-GEN-500) | 500 | Internal error |
| [HEPH-VAL-422](/errors/HEPH-VAL-422) | 422 | Validation failed |
| [HEPH-NF-404](/errors/HEPH-NF-404) | 404 | Resource not found |
| [HEPH-AUTH-401](/errors/HEPH-AUTH-401) | 401 | Authentication required |
| [HEPH-AUTH-403](/errors/HEPH-AUTH-403) | 403 | Permission denied |
| [HEPH-RATE-429](/errors/HEPH-RATE-429) | 429 | Rate limit exceeded |
| [HEPH-IDEMP-400](/errors/HEPH-IDEMP-400) | 400 | Idempotency key missing or malformed |
| [HEPH-IDEMP-409](/errors/HEPH-IDEMP-409) | 409 | Original request still in flight |
| [HEPH-IDEMP-422](/errors/HEPH-IDEMP-422) | 422 | Idempotency key reused with a different payload |
| [HEPH-MONEY-422](/errors/HEPH-MONEY-422) | 422 | Invalid money amount |
| [HEPH-MONEY-409](/errors/HEPH-MONEY-409) | 409 | Currency mismatch |
| [HEPH-WH-401](/errors/HEPH-WH-401) | 401 | Webhook signature invalid or expired |

The registry is `spec/errors.yaml`; the pages are generated from it.
